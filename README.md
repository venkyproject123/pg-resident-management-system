# PG Resident Management System

## About the Project
A web application that helps PG owners manage resident records.

## Features
- Owner Login
- Add Resident
- View Resident Details
- Update Resident Details
- Delete Resident Records

## Technologies Used
- Java 21
- Spring Boot
- Spring Data JPA
- MySQL
- Maven

## Future Enhancements
- QR Code-Based Registration
- Resident Login

Under Development
